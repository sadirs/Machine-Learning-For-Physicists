# Machine Learning for Physicists: A Hands-On Course

A course workspace for lecture notes, Jupyter notebooks, exercises, and scientific mini-projects.

## Course Status

This initial release contains a complete curriculum and editable templates. Lesson notes, assignments, and runnable demonstrations still need to be authored. Original course materials are linked in [Resources](resources/course_links.md).

## Getting Started

See [Installation](setup/installation.md). Follow the modules in numerical order. Each module contains topic notes, a notebook template, an assignment template, and a solutions template.
